You can give LLMs skill files to help them perform specific tasks.

Agentskills.io has a [quickstart guide](https://agentskills.io/skill-creation/quickstart) to help you write a skill file for VS Code Copilot (not sure if you can apply the method to other agents).

Anthropic has an [Agent Skill guide](https://support.claude.com/en/articles/12512198-how-to-create-custom-skills#h_db275d1972) for giving skills to Claude.

Anthropic also has some public [example skills](https://github.com/anthropics/skills/tree/main/skills).
