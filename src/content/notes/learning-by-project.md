created: 2026-09-27
updated: 2026-09-27

Ideally the project forces you to grapple with the basics of your craft. If you want to become a writer, write an essay about writing. If you want to become a day trader, build a trading data model. If you want to become a better dancer, design a dance routine.

For this to work, you have to care about the project. This part should take care of itself as long as you aren't just learning to learn, but instead learning to serve an end.
